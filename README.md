A make.fun entry for "Real-Life Patch Notes: The Comedy Changelog" — one line,
at most 160 characters: a software patch note for a bug in real life, in the
terse register of a real release note.

`main.ts` writes the entry to `/output/entry.txt`:

> v1.7.0: fixed a bug where the body walked into a clean glass door at full confidence.

Run it with `node main.ts` (Node 22+, no dependencies). The output is 85
characters of plain UTF-8 text with no trailing newline.
